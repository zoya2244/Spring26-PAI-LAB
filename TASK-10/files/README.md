# 🎓 University Admission Chatbot

A Flask-powered chatbot that answers questions about university admissions.

## Setup & Run

```bash
pip install flask
python app.py
```

Then open: http://localhost:5000

## Features

- 6 programs: CS, Business, Data Science, Mechanical Engineering, Psychology, Medicine
- Application deadlines (Early Decision, Regular, Transfer, etc.)
- Admission requirements & required documents
- Tuition fees per program
- Financial aid & scholarships
- International student info
- Contact details
- Quick-action buttons in the UI
